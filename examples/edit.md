# 改稿例

## 入力

```text
近年、議事録の有効活用が注目されています。これは単なる記録ではありません。組織の未来を変えるナレッジアセットです。会議終了後は運営担当が内容を確認させていただく形となっており、決定事項と担当者を記録して関係者への共有を実施することができます。これにより次の会議で同じ確認を繰り返さずに済みます。
```

## 出力例

```text
会議が終わったら、運営担当が議事録を確認します。決定事項と担当者を記録し、関係者へ共有できます。これにより、次の会議で同じ確認を繰り返さずに済みます。

## 変更点

- 根拠のない「注目されています」を削りました。
- 「ナレッジアセット」を、議事録に残す具体的な情報へ置き換えました。
- 動作主を「運営担当」と明記し、過剰敬語と「こと」の殻を除きました。
```
