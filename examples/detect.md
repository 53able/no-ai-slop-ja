# 検出例

## 入力

```text
これは単なるアップデートではありません。業界の未来を変える重要な転換点です。多くの専門家も、その革新性に注目しています。
```

## 出力例

### 二項対立の決めぜりふ

- **該当箇所**: 「単なるアップデートではありません。業界の未来を変える」
- **理由**: 否定と大きな抽象表現を組み合わせ、変更内容を示していません。
- **直し方**: アップデートで変わった機能や利用者への影響を直接示します。

### 重要性の自己申告

- **該当箇所**: 「重要な転換点です」
- **理由**: 何が以前と違うのかを示さず、重要だと評価しています。
- **直し方**: 初めて可能になったことや運用上の変更を示します。

### 根拠のない帰属

- **該当箇所**: 「多くの専門家も、その革新性に注目しています」
- **理由**: 専門家と根拠を特定できません。
- **直し方**: 出典と発言者を示すか、この主張を削ります。

この出力は、文章がAIによって書かれたかどうかを判定していません。
